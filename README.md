# Keystroke Logging Demonstration (Educational)

This project demonstrates how keyboard input events are captured at the application level.

This project is created strictly for educational and cybersecurity awareness purposes.
It is user-controlled and does not run in the background.
No malicious intent or unauthorized data collection is involved.

## Technologies Used
- Python
- Tkinter
- pynput

## Note
This project is intended only for learning and demonstration purposes.
